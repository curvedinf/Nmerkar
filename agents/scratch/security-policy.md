# Security disclosure policy

Natural-language allowlist for the pre-commit security gate
(`agents/skills/triggered/security-hygiene-check/SKILL.md`). It records what
information may be disclosed, for what purpose, and under which conditions;
every file remains inspectable, and existing occurrence is not consent.

- **Standing permissions: none approved yet.** No disclosure scope has been
  recorded by the user, so every finding requires an explicit disposition
  (remove/redact, exclude from the commit, or retain as intentional) before
  committing.
- One-time dispositions and later standing permissions are recorded here at
  the scope the user approved, never broadened by inference, and without
  sensitive values.
